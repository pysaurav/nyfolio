## Color Roles & Ratios (Screen)

- **Primary — Caribbean Current**: 60% (navigation, section headings, key rails)
- **Secondary — Teal**: 10% (links, secondary actions)
- **Accent — Tyrian Purple**: 5-10% (CTAs, quotes, highlights)
- **Panels — Bone**: 10-15% (cards, sidebars, quotes)
- **Background — Anti-Flash White**: 10-15% (page background/whitespace)
- **Text — Ink**: Body text (AAA on light)
- **Meta text — Slate**: Labels, captions, UI help

---

## Accessibility Requirements

**Passing Combinations**:
- White text on Tyrian Purple (`#611C32`) → AAA contrast for buttons
- Ink (`#0E1B2A`) on Anti-Flash White (`#F2F5F7`) → AAA
- Ink (`#0E1B2A`) on Bone (`#E7D9C4`) → AAA

**Avoid**:
- Tyrian text on dark teal/blue backgrounds (fails contrast)
- Keep large areas light for readability

## Logo System — River × Grid × Seed

**Meaning**: flow (Pisces), standards (Saturn), root/star (Mūla/Scorpio)

### Construction & Use

**Geometry**:
- 1:1 circle on 24-unit grid
- Outer stroke: 2.5px
- River: 3px width

**Colors**:
- Teal ring
- Blue river
- Tyrian seed
- For small sizes: single-color Ink version

**Clearspace**: ≥ seed diameter around the mark

**Minimum size**: 16px

**Lockups**:
1. Mark only
2. Mark + wordmark (horizontal)
3. Stacked version

### Don'ts

No gradients  
No drop-shadows  
No color swaps on the seed  
No busy patterns behind the mark

## Typography — Voice & Pairings

**Humanist sans for UI, editorial serif for essays.**

### Primary Sans (UI)

**Fonts**: Inter / Source Sans 3 / Söhne*

**Use for**: headings, buttons, navigation

**Sizes**:
- H1: 32-40px
- H2: 24-28px
- Body: 16-18px
- Line-height: 1.55-1.65

### Editorial Serif (Long Reads)

**Fonts**: Newsreader / EB Garamond / Literata

**Use for**: photo essays and case studies

**Setting**: On Anti-Flash White background with Ink text for AAA contrast

## Typesetting Rules

- Avoid all-caps paragraphs
- Use Small Caps for labels only
- **Tracking**:
  - +2 for UI labels
  - 0 to +1 for headings
  - 0 for body text
- Use Teal focus rings (2px) for accessibility
- Underline all links

## Do / Don't

### Do

- Maintain light backgrounds; let photos breathe
- Keep CTAs in Tyrian Purple
- Use Blue/Teal for standard links to avoid confusion
- Use generous spacing (8/12/16/24/32 grid)
- Prefer soft elevation over heavy effects

### Don't

- Heavy shadows
- Gradients
- Cluttered layouts
- Dark backgrounds for large content areas
